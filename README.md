# 🧸 Teddy – Python Voice Assistant

Teddy is a Python-based voice assistant that listens to voice commands and performs useful tasks such as calculations, web searches, Wikipedia searches, weather updates, YouTube playback, jokes, and more.

## ✨ Features

* 🎙️ Voice command recognition
* 🧸 Wake word – "Hey Teddy"
* 🕐 Current time
* 📅 Current date
* 🧮 Calculator
* 📚 Wikipedia information
* 🌦️ Weather updates
* 🔋 Battery percentage
* 😂 Jokes
* 🎵 YouTube music/video playback
* 🔎 Google search
* 👋 Greetings
* 🛑 Voice-based exit commands

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* PyWhatKit
* Requests
* PyJokes
* Psutil
* Wikipedia API

## ▶️ How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run Teddy:

```bash
python teddy.py
```

Then say:

**"Hey Teddy"**

Teddy will respond:

**"Yes, I'm listening."**

You can then give commands such as:

* "What is the time?"
* "What is Python?"
* "Who is Albert Einstein?"
* "What is 12 plus 2?"
* "Tell me a joke"
* "What is the weather?"
* "Search Google for data analytics"
* "Play music"
* "Bye Teddy"
